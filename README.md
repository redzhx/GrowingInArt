# 成长画册 · Growing In Art

记录 2013–2026 年间孩子们的绘画与手工成长轨迹。内容从有道云笔记导出，包含 460+ 条笔记及对应的作品图片、视频等素材。

## 项目结构
```
宝贝作品/           # 笔记与素材（~470 条）
  {标题}.md         # Markdown 笔记，含元数据头
  {标题}/           # 对应素材目录（图片、视频、PDF 等）
public/             # 网页画廊（HTML/CSS/JS）
scripts/            # 工具脚本
```

每条笔记由 **同名 .md 文件** 和 **同名子目录** 组成配对单元，文件引用使用 URL 编码的相对路径指向素材。

## 笔记格式

每篇笔记以 YAML 式元数据开头：

```markdown
# 标题 (日期 + 描述，可选 @孩子名)

Date: YYYY/MM/DD
星期: DayOfWeek
年龄: DecimalAge
生日: YYYY/MM/DD
Tags: 作品, 含视频
```

## 网页画廊

`public/` 目录包含一个静态网页画廊，支持按孩子筛选和时间轴浏览。用任意 HTTP 服务器即可启动：

```bash
cd public && python3 -m http.server 8080
```

## CSV 索引

根目录下的两个 CSV 文件是有道云笔记的数据库导出，`_all.csv` 变体额外包含 `Created Time` 字段，可作为笔记的原始时间索引。
