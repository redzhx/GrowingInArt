# 语音提醒 Hook 方案

> 需求：在 Claude Code 完成任务时，用语音提醒我。

## 查询结果：已有现成方案

### Option 1: macOS `say` 命令（最简单）
直接用系统自带的 TTS 引擎，在 `Stop` hook 中配置：
```json
{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "say '任务完成'"
          }
        ]
      }
    ]
  }
}
```

### Option 2: [claude-code-voice](https://www.npmjs.com/package/claude-code-voice)
npm 包，一键安装，功能最全：
- 中文语音播报（含 AI 摘要）
- 会话开始/结束问候
- 按 hook 类型静音
- 跨平台（macOS/Windows/Linux）
- 安装：`npx claude-code-voice`

### Option 3: [claude-audio-hooks](https://www.npmjs.com/package/claude-audio-hooks)
npm 包：
- 系统音效（完成/提醒）
- TTS 摘要（通过 ElevenLabs）
- 安装：`npx claude-audio-hooks install`

### Option 4: [clarvis](https://github.com/nickpending/clarvis)
Jarvis 风格语音通知：
- "Sir, I have completed..."
- LLM 智能摘要（支持 OpenAI/Ollama）
- 配置方式：管道 `cat | clarvis`

### Option 5: [Claude Code Audio Hooks](https://github.com/ChanMeng666/claude-code-audio-hooks)
- 14 种通知类型
- 桌面通知 + 音效 + 可选 TTS
- 安装：`curl -sL https://raw.githubusercontent.com/ChanMeng666/claude-code-audio-hooks/master/scripts/quick-setup.sh | bash`
